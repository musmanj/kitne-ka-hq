# Day 1 — data-source access matrix
Owner: CTO. Assessment/retrieval date: **9 Nov 2026, PKT (UTC+5)**. Proposed operational policy, not a legal opinion. No signups, credentials, commercial API calls, outreach or production ingestion performed.

## Executive finding
**No broad Pakistan marketplace ingestion source is yet cleared for production.** Robots.txt is a crawl directive, NOT a licence; public visibility, a search-engine exception, an affiliate programme, and a third-party scraper are not permission for Kitne Ka. Default every adapter to disabled. Require explicit permitted method, commercial use/redisplay/caching rights, licence expiry, and approved rate limits in a source registry. Robots and terms apply cumulatively; stricter restriction wins. Do not change user agents to evade named-agent blocks. A permitted API contract can authorise its API independently of website crawling.

Prioritise a retailer-owned CSV/JSON export with written commercial comparison permission; seek it only after Founder authorises outreach. Keep the input journey working through manual confirmation and rights-cleared user images. Never silently replace market evidence with synthetic data or imply product-wide coverage.

## Fetched legal evidence and quotations
All URLs below retrieved **2026-11-09 PKT**. HTTP status and redirects are recorded in `evidence/manifest*.json`; raw bodies and readable extractions are retained there. Failed/empty pages yield **no quoted clause**, not a presumption of permission. Terms may change; re-check before enabling an adapter and weekly during MVP. This research fetched policies only, not production listing datasets.

- R1 https://www.olx.com.pk/robots.txt — direct public request 200 (WebFetch was 403). `User-agent: *`, `Disallow: /api/`, `Disallow: /chat/`, `Disallow: /profile/`. No blanket allow to commercially aggregate.

## Production acceptance / legal checklist
For each enabled source record: owner, permitted endpoints/method, signed permission or applicable API licence URL/version/date, robots snapshot/path evaluation if crawling, commercial display + caching + deletion rights, allowed fields, rate cap, expiry/recheck, fee approval, contact/owner, kill-switch. No session-cookie scraping or unpublished endpoints. Fetch only allowlisted HTTPS destinations; no arbitrary user URL fetch. User target screenshots are private per-request input; do not accumulate restricted-platform screenshots into an ersatz scraped database. A user’s own fresh direct quote can become evidence only with rights, independent provenance, consent and anti-manipulation review.

## Launch risk and recommendation
Used/PTA-segment coverage is particularly at risk if OLX is unavailable. Do not estimate used prices by depreciating new prices or relaxing variant constraints. G1: Founder/PM decide honest launch coverage expectations; G2: demonstrate at least one legally usable real evidence pathway, or escalate a scope decision (not a date slip). Fixtures prove code only, never live market coverage. Actual sample counts and supported SKUs must be reported, not assumed.
