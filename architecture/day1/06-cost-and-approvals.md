## Planning assumptions (NOT measured usage or quotes)
1,000 checks/month; all1,000 optionally invoke one extraction model; **3,000 metered input tokens total including image/text +500 output/thinking tokens per invocation**. Images vary in token cost; this is an estimation assumption to validate, not “one image costs3k tokens”. No automatic dual-provider retry, no grounding, web-search/embedding tools or hosted containers. About20 dynamic requests/check =20,000/month before share/views; peak below100k/day assumed, not load tested.1,000 one-query search calls/month optional; caching may reduce but no savings assumed. DB<=100MB, egress<1GB/month, transient image retained only in request memory, <=1,000 small sanitised public snapshots. One production project, one free preview where allowed. One deployer. No custom domain required for Day14 live URL.

## Recommended envelope
- Free-only local OCR/manual + free app/DB: **$0/month targeted**, but this does not resolve data access or guarantee screenshot extraction quality/10ms share-rendering CPU.
- Recommended optional paid extraction + free app/DB: **$2.15/month estimated**; with likely CPU contingency **$7.15/month**. Propose Founder maximum **$15/month** envelope for extraction+Worker only, no automatic upgrade; app hard-caps remotely billed actions.
- Adding SerpAPI1k/month: **$27.15** without Worker upgrade, **$32.15** with it; needs separate approval and legal gate. Not requested as default since evidence rights unresolved.
- Next/Vercel alternative+Supabase Free+Gemini: **$22.15+** (or +$25 optional search). Supabase Pro adds$25; choices are alternatives unless explicitly stated additive.
- Prices can change. No PKR conversion given because FX not fetched; Founder approves in vendor-billed USD with bank FX/tax headroom. Budgets/alerts are not billing hard limits: enforce app token quotas, source quotas, timeouts and kill-switches. Any uncapped provider overage must be disabled or explicitly accepted.
